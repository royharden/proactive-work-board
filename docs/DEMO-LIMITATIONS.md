## Concrete integration observations required

The minimal shared snapshot envelope alone is insufficient for a verified result.
D1/D3 must supply the following demo-only envelope observations; P01 wire records
are never extended. Until INT reconciles this seam, results intentionally remain
pending rather than asserting absent duplicate/binding evidence.

- `before.verification_context` contains the exact P01 `proposal` and `decision`.
  The verifier recomputes the complete proposal digest, compares compiled writes,
  IDs, full read binding, observed row versions, scope revision and valid times.
- `after.effect_history` and `delayed.effect_history` contain chronological entries
  `{before, after, receipt?, actor_kind, actor_label}` from seed to observation.
  Entry snapshots contain core board/tick/revision/records, without recursive
  history/context. `history_complete: true` declares no omitted mutations. Every
  adjacent observation must join by core digest, and include this exact apply pair
  and receipt. Time-only final snapshots must also join through an entry. This is
  observed host history, not receipt-only actual-write claims.
- Full history reconstructs per-effect class, normalized target and public epochs
  without controller imports/intent-key grouping. Human supersession is attribution
  only. Observable blocker/state and effective-boundary changes start relevant
  task epochs; unrelated person edits and task title/description do not. Edited
  non-arm business prose has uncertain substantive meaning: it makes historical
  proof incomplete rather than resetting an epoch and hiding repeats. No latent
  outcome label is consulted. Producer completeness/actor attribution is a local
  engineering assumption, never authentication or independent custody proof.
- Delayed observations must cover at least apply tick +8, including intervening
  mutations. Missing, truncated, discontinuous or malformed observations cannot
  produce verified. Missing receipt identities use explicit `unobserved` / zero
  digest placeholders only in failed/pending records, not fabricated receipts.

`workboard.report.render.render_report(demo_trace, effect_records)` returns
`{'html': str, 'json': str, 'text': str}` with no writes. It consumes shared
`m20-demo-trace-v1` (SCRIPTED, measurement false, stages and other shared fields),
shows the supplied observations without upgrading them, and labels the output
SYNTHETIC / SCRIPTED / NO PAID CALLS / NOT A MEASUREMENT. Every value and URL is
plain text; HTML is escaped with no scripts/active links and a restrictive CSP.
JSON/text are data artifacts, not HTML fragments. D3 owns later artifact writes.
